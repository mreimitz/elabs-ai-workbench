# Testing Console UI Concept

## Objective

Work out what the agent testing console should look like — the conversation, the cost and context rails, the inspector and the replay experience — before any of it was built.

## Why now / what it feeds

The run engine was designed first; the console that operators would actually live in had no concept.

## Scope

**In:** The console's information architecture, the run conversation, KPI rails, the step inspector and replay.

**Out:** The run engine itself and the grading layer.

## Deliverable

A UI concept feeding the testing roadmap item.

## Success criteria

Every element of the console has a stated purpose and a place in the layout.
