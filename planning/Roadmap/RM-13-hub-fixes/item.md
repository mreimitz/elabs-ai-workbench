# Assistant Hub defect-fix workstream

## Goal

Fix the six verified root causes from the Assistant Hub diagnosis: callable and honestly scoped MCP tools in every hub session, real tool-using mission subagents with inherited grants, live transcripts and real costs.

## Why it matters

The Hub shipped with mission subagents that could not actually use tools, so missions produced confident output from no evidence.

## Milestones

- [ ] Diagnose and lock the root causes.
- [ ] Fix tool callability and scoping.
- [ ] Make mission subagents real sessions.
- [ ] Verify transcripts and cost attribution.
