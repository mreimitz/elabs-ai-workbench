# Assistant operability — every view exposes an assistant interface

## Goal

Make it a hard, test-gated rule that every route and addressable view resolves to a real, page-appropriate assistant starter surface or a reasoned exemption, and bring the Hub up to that bar.

## Why it matters

Nothing in the app required a new view to expose an assistant interface, so whole features shipped with the dock falling back to generic global suggestions.

## Milestones

- [ ] Phase 1 — the route manifest and the gate.
- [ ] Phase 2 — Hub starter surfaces and read tools.
- [ ] Phase 3 — page hooks and pins.
- [ ] Phase 4 — the edit-time nudge and documentation.
- [ ] Phase 5 — Hub write operability.
