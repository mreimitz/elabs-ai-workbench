# Assistant Hub — the full-page multi-model, multi-agent assistant

## Goal

Build the full-page Assistant: general-purpose identity, chat, research and mission session modes, a planner that proposes subagent teams with per-agent grants and budgets, declarative generative UI, artifacts, memory and usage telemetry.

## Why it matters

The dock operates the current page; the owner also wanted a general-purpose, multi-agent workspace that shows what the platform can do.
