# Skill IDE — an enterprise IDE for Agent Skills

## Goal

Turn the Skills and SkillFlow features into a full IDE: per-command entry-point flows, canvas flow editing, a file and folder workspace, a quality engine, scan-aware tool validation, trigger management, publish to GitHub and unified flow-and-code editing.

## Why it matters

Authoring a skill meant editing files blind, with no validation against the servers the skill would actually call.

## Milestones

- [ ] Phases 1-3 — the workspace, commands and multiflow canvas.
- [ ] Phases 4-6 — the quality engine, tool validation and triggers.
- [ ] Phases 7-9 — publishing, server-bound authoring and unified flow-and-code editing.
