# Skills registry and inspector

## Goal

Register Agent Skills from an upload or a GitHub import, version them, pull new versions, inspect the rendered skill with its token footprint, security surface, file explorer and full-tree diff, and attach them to test environments.

## Why it matters

Skills consume model context exactly as tool definitions do, and the workbench could neither measure nor manage them.

- [ ] Phase 1 — the registry and the inspector.
