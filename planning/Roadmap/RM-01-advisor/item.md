# Advisor — evidenced recommendations from measurements

## Goal

Turn the workbench's measurements into concrete, evidenced recommendations: unused-tool trims with token savings, description bloat, eager-versus-deferred comparison, cross-server overlap, grade-aware trims, skill return on investment and a fleet report.

## Why it matters

The app knows footprints, runtime behavior, grades and costs, but an operator still had to work out what to change; advice closes the gap between measurement and action.
