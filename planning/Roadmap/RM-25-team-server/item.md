# Team server — shared-instance operation

## Goal

Make the app operable as a shared instance: local-account authentication, admin, editor and viewer roles, an append-only audit log, and backup, restore and retention, while staying one self-hosted container.

## Why it matters

The app assumed a single local owner, which blocks any team from running one instance together.

- [ ] Phase 2 — the audit log.
