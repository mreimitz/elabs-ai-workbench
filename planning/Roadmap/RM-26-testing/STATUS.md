the next **open** WPs whose **dependencies are done**, runs them with parallel worktree sub-agents,
and ticks a box **only** when that WP's Acceptance is met and the gate
(`pnpm typecheck && pnpm test && pnpm build`) is green.

**Legend:** `[ ]` open · `[x]` done. A trailing `status:` note marks `in progress` / `in review`.
Done lines record the date + branch: `… — done <YYYY-MM-DD> · wp/testing/<id>`.
