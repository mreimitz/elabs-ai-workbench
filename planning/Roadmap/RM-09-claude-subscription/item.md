# Claude subscription as a run model

## Goal

Make Claude models on the owner's signed-in subscription a first-class selectable run model for single and suite runs, with an explicit estimate marker on the metrics that are not provider-exact.

## Why it matters

Test runs on a metered API key cost money for work the owner has already paid for through a subscription.

## Milestones

- [ ] Phase 1 — the credential and the model surface.
- [ ] Phase 2 — the run path and metering.
- [ ] Phase 3 — accuracy markers and hardening.
