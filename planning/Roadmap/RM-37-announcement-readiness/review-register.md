# Review register — every action point from the 2026-08 multi-persona review

This register is the single deduplicated list of action points behind RM-37. One row is one concrete change; where several reviewers asked for the same change the row carries every source id. It is the index the work packages in this folder (`./wp-*.md`) are cut from, and the place to check that a finding has a home.

**Sources.** Nine persona reviews of the running app and the repo copy (sections B, C and D of each report only), plus the live walkthrough of 2026-08-21 at 1440×900:

**Id scheme.** Source ids are the reports' own. The walkthrough carries no ids of its own, so its defect and friction statements are numbered `WT-01 … WT-85` in the order they appear in `walkthrough.md` (per-view sections; the closing "cross-cutting patterns" recap restates earlier items and gets no ids). Every source id appears in exactly one register row, or in the "Covered by RM-36" line, or in the "Excluded" line at the end. `Ref` = `RM37-nnn`, numbered in work-package order (0.1 → 4.3). Priority P0–P3 is a scheduling signal only. Effort: S ≤ 1 day · M 2–5 days · L > 1 week. Server and environment names from the owner's instance are written generically; file paths come from the persona reports.
