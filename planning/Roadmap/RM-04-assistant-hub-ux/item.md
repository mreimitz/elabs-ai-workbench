# Assistant Hub UX — rebuild onto the app shell grammar

## Goal

Rebuild every Assistant Hub surface onto the app's own shell grammar per the owner-approved concept: a meta rail, a sessions table, the workforce section, scoped memory and a four-item navigation.

## Why it matters

The Hub shipped with its own layout language, so it read as a separate product bolted onto the workbench rather than part of it.
