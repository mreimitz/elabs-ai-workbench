# Assistant Hub — UI Wave (2026-07-21)

Owner-driven UI/UX wave on top of the v1-fixes wave (see `v1-fixes-2026-07-20.md`). Scope came from the owner's walkthrough of session `o8cK7ICodepdc5JvlI4QB` and the Agents/Projects views, plus a live browser audit. All units verified by the full gate: web typecheck clean, web suite green (275 test files), hub API suite 717/717, impacted non-hub API tests 668/668, shared 82/82, biome clean.

## Units

### U1 — Mission card: the graph IS the selector
The duplicate 2-up agent-card grid under the topology graph is gone. Clicking a node on the inline board graph drives the detail box below (any spawned agent is selectable, not only reported ones); the Status / Report / Live tab choice PERSISTS across node switches in both the inline board and the expand modal (previously a `key` remount reset it to Status every switch). `MissionBoard.tsx`, `MissionExpandDialog.tsx`, tests in `Mission.test.tsx` / `MissionExpandDialog.test.tsx`.

### U2 — Expand opens a real modal
`ExpandableTable` (markdown tables in chat, agent reports, the outputs viewer) and the markdown viewer's expand no longer take over the raw viewport; they open a proper dialog (backdrop, title, rounded frame, Esc/close). `features/testing/ExpandableTable.tsx`, `ChatMarkdown.tsx`, `ArtifactCanvas.tsx`.

### U3 — Transcript + GenUI polish
Density pass over the conversation: card-in-card nesting flattened, quieter tool chips, redesigned `prompt_user` options/forms, aligned GenUI components, soft entry/streaming motion (the `motion` library, respecting `prefers-reduced-motion`). `ConversationPane.tsx`, `genui/*`, `AgentTranscript.tsx`, `SourcesPanel.tsx`.

### U4 — Composer rebuilt
State-of-the-art layout: clean field, organized control row, non-truncating chips, proper paddings, single accent send. `Composer.tsx`.

### U5 — Agents & Crews as an organization builder
The left rail is a real expandable TREE over the existing model: crews expand to member agents (avatar + role), inline create (crews-header "+" for a new crew, per-crew hover "+" for a new agent scoped to that crew), drag agents between crews, Unassigned/Archived branches, keyboard-accessible "Move to crew" menu. The Directory toolbar was de-duplicated (the "+ New" menu moved to the page header). The Org-chart crash (React #185 infinite update loop when opening a crew scope on the org tab) is fixed. `workforce/*`, `agents/AgentsView.tsx`.

### U6 — Projects redesigned + repaired
Library rail + rich detail with proper sections (instructions, pinned files, memory, member sessions), fixed flows, real empty states. `projects/*` including the new `EditorSection.tsx`.

### U7 — Clickable tables read as rows, not buttons
App-wide list tables (`lib/table.tsx` + Sessions/Scans/Servers/Audit/Issue views): whole row clickable with hover treatment, first-column link and trailing "…" menu transparent/ghost (visible on hover/focus), menu clicks never navigate.
