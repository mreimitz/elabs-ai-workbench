Environment — all servers combined 1
Total tools across all servers within the model's cap aggregatestatic_connection env.toolCount.aggregateCap

Sums the tools of ALL connected MCP servers (plus built-in/model tools) and checks the total against the model/host AGGREGATE cap — the limit that actually binds (Claude 10k catalog, OpenAI 128, Gemini 512, Cursor 40). This is the real tool-count gate; SERVER_TOOL_COUNT_HARD is only a single-server upper bound.

Trim the active server set, disable unused tools, or enable tool-search/deferral so the COMBINED tool count across all connected servers stays under the cap. The cap is an environment-wide budget shared by every server.
